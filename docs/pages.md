# 페이지 명세

원본: "홈페이지 프로토타입 허브"에 정리된 claude.ai 아티팩트 10종 (고객용 7 · 관리자 3, 최종 수정 2026-10-07 기준).
각 페이지의 디자인·문구·인터랙션은 프로토타입을 그대로 따르며, 아래에는 기능 요약과 **프로토타입 대비 바뀐 점**만 적습니다.

## 공통

- GNB: 클래스(`/classes`) · 온라인 강의(`/classes?cat=온라인`) · 아카데미 소개(`/about`, 10.14 "아카데미"에서 이름 변경) · 수강 안내(`/guide`), 우측 검색 아이콘(메인 검색창으로 이동)·상담 신청(`/about?tab=way`).
- 푸터: 아카데미 소개/강사 소개/오시는 길, 수강 절차/FAQ/환불 규정 링크. 비주얼살롱·트리필드 외부 링크는 URL 미정이라 `#`.
- 프로토타입의 `claude.ai/artifact/...` 링크와 비어 있던 `#` 링크는 모두 내부 라우트로 연결.
- 브라우저 `alert/confirm` 대신 페이지 내 모달·토스트 사용.

## 고객용

### 메인 `/`
- 다크 히어로 + 스크롤하면 밝아지는 헤더.
- 내부 검색: 인덱스(클래스·강사·일정·혜택·위치·FAQ·마이페이지·상담), 동의어·오타 사전, 불용어 제거, "레벨2 vs 3" 비교 질문, 추천 질문 13종(히어로에는 3개 노출), 결과 없음 시 카톡·전화 안내. 입력 중 220ms 디바운스.
- 성장 로드맵: 경력 탭(1년 미만/1~3년/3년 이상 → 추천 STEP 1/2/4), 컬럼 hover/클릭 시 카드 표시, STEP 01~04 실사 hover 사진 4장(크기 120%, 데스크톱 한정). 높이 440px.
- 영역 순서·노출과 모든 문구는 디자인 모드 콘텐츠(`siteContent.ts`)를 따른다. '이번 기수 모집중'은 노출 개수(3/6)·우선순위(마감 임박 순/개강일 순/관리 순서) 규칙으로 클래스 데이터에서 자동 선택.
- 이번 기수 모집중 3카드, 프로그램 3종("전체 보기" → 목록 분류 필터), 온라인 배너, 강사·후기(예시 데이터), 비주얼살롱 밴드.
- 변경: 모집중 카드의 배지·개강일은 데이터에서 계산. 검색 결과는 새 탭이 아니라 같은 탭으로 이동.

### 클래스 목록 `/classes`
- 로드맵(상태 pill + 단계별 연결 강의 칩, 카드 "목록에서 보기" → 해당 레벨 카드로 스크롤·하이라이트).
- 상태 탭(전체=종료 제외 / 이번 기수 모집중 / 상시 수강 / 개설 대기 / 종료된 클래스) + 분류·분야·대상·요일·수료증·비전공자 필터, 검색, 초기화.
- 레벨별 보기: 정석 레벨 1~4 순서 카드 + 단계에 연결된 특강·경영·온라인 카드. 수업별 보기: 분류별 가로 스크롤 로우.
- 모든 카드 1:1 썸네일 자리, 빈 상태 화면.
- 변경: `?cat=`이 정석 외 분류면 자동으로 "수업별 보기"로 시작(레벨별 보기에선 해당 분류가 비어 보이던 문제). 버튼은 신청·결제/상세로 연결.

### 클래스 상세 `/classes/[slug]`
- 상단: 정사각 썸네일 + 분류·상태 배지 + 제목 + 일정/장소 요약 2줄 (모바일은 작은 썸네일 가로 배치).
- 온라인 강의: 1강 무료 미리보기(30초 재생 시뮬레이션).
- 탭: 상세정보(3:8 상세 이미지 자리, 이런 분께, 커리큘럼 "전체 N개 보기", 강사·준비물) / 구매평 / Q&A(아코디언) / 반품·교환.
- sticky 구매박스 + 모바일 하단 고정 바. 신청 버튼 → `/checkout?cls=slug`. 개설 대기·예정은 "개설 알림 신청"(토글), 마감·종료는 비활성.
- 변경: DEMO 오프라인/온라인 전환 바 제거 → 클래스별 실제 데이터. 상세 콘텐츠 미등록 클래스는 기본 정보로 채운 화면.

### 아카데미 소개 `/about`
- 탭 5종(`?tab=` 딥링크): 소개(에디토리얼 레이아웃·Q&A 트리오·스플릿 섹션·시설·IFBS·통계·지점·클로징 쿼트·연혁) / 강사 / 갤러리 / 오시는 길(지도 자리) / 제휴 문의 폼(필수값 검증 후 접수 안내).

### 수강 안내 `/guide`
- 수강 절차 7단계 타임라인 · FAQ 4그룹 아코디언 · 환불 규정 표 + 법령 안내.

### 마이페이지 `/mypage`
- 프로필 카드, 탭 4종: 신청 내역(취소 신청) / 결제 내역(영수증 모달 — 과세 시 공급가액+부가세, 면세 표시) / 온라인 수강권한(진도율) / 내 정보(비밀번호 확인 검증, 회원 탈퇴 확인 모달).

### 신청 · 결제 `/checkout?cls=`
- 4단계 스테퍼(1단계 "클래스 상세"는 완료 상태로 상세로 돌아가는 링크).
- 신청 정보(이름·휴대폰 검증) + 필수 동의(정석 상위 레벨은 선수 과정 확인 추가) → 결제 수단 4종(카드/간편결제/계좌이체/가상계좌) → 처리중 → 실패(재시도·수단 변경) / 완료(가상계좌는 입금 대기 안내).
- 과세/면세 금액 표시. `?cls=offline|online`(프로토타입 링크)도 호환.
- 변경: DEMO 바의 "결제 실패 시뮬레이션"은 결제 단계 하단의 테스트용 체크박스로 이동. 신청 불가 상태(마감·종료·대기) 안내 화면 추가.

## 관리자

### 대시보드 `/admin`
- 상단 메뉴 첫 항목 "대시보드"(10.14 "클래스 관리"에서 변경), 우측 상단 '디자인 모드' 버튼. 매출 관리 화면도 동일.
- 매출 히어로(전월 대비, 최근 7일 스파크라인) → 결제 관리로 이동, 매출 타일 4개, 분류별 매출 막대.
- 클래스 현황 요약 5개, 상태·분류 필터 + 검색.
- 카드: 잔여석·진행 바(마감임박/마감 색상), 정원 ± 조정, 개강일 인라인 수정(상태 자동 갱신), 지금 바로 종료(확인 모달)/종료 취소.
- '콘텐츠 관리' 버튼 → 클래스 콘텐츠 관리 화면, '기본 정보' → 클래스 기본 정보, '미리보기' → 고객용 상세 페이지(새 탭).

### 디자인 모드 (페이지 관리) `/admin/design` — 10.14 추가
- 대시보드·매출 관리 우측 상단 **'디자인 모드'** 버튼으로 진입, **'대시보드로 나가기'**로 복귀.
- 고객용 7개 페이지 편집: 메인 · 클래스 목록 · 클래스 상세(공통 문구) · 아카데미 소개(5개 탭) · 수강 안내(3개 탭) · 마이페이지(4개 탭) · 신청·결제.
- 왼쪽 미리보기(PC/모바일)에서 영역을 클릭하면 오른쪽 폼이 열리고, 수정 중인 영역은 민트 테두리로 표시.
- 영역별 폼: 글·여러 줄 글·선택·사진(권장 사이즈/비율 표기, 5MB 제한, 권장 폭으로 축소 저장, 비율·해상도 경고)·목록(추가/삭제/순서 변경, 고정 개수 목록은 추가·삭제 없음).
- 메인·클래스 목록은 ▲▼로 영역 순서 변경, 스위치로 숨김. 나머지 페이지는 구성 고정.
- 아카데미 소개: 글 입력칸마다 **'Aa 글자 스타일'**(크기 %·자간·줄 간격·굵기·정렬).
- "수정 중(초안) ↔ 지금 사이트 화면" 비교, 게시 전까지 초안. 게시 시 변경 메모와 함께 버전 기록, 이전 버전 보기·복구.
- 현재 게시본·버전 기록은 **이 브라우저(localStorage)** 에 저장된다. 메인 페이지·상단 메뉴·푸터는 `src/data/siteContent.ts` 기본값을 읽어 렌더하므로, 백엔드에서 게시본을 내려주면 그대로 반영된다(`docs/backend-todo.md`).

### 클래스 등록 · 편집 (기본 정보) / 클래스 콘텐츠 관리
- 10.14부터 두 화면으로 분리: 기본 정보 `/admin/classes/new`, `/admin/classes/[id]/edit` · 콘텐츠 관리 `/admin/classes/[id]/content` (대시보드 카드의 '콘텐츠 관리' 버튼, 하단에 '미리보기 ↗').
- 기본 정보: 클래스명, 분류(정석/특강/세미나/경영/온라인), 운영 유형(기수제/개설 대기/온라인)에 따라 조건부 입력(세미나 장소·최근 장소 칩, 개설 대기 안내, 온라인 수강 기간), 성장 로드맵 단계 연결, 일정·정원, 가격(자동 천단위)·과세/면세(공급가액·부가세 계산), 한 줄 요약(40자).
- 콘텐츠 관리: 썸네일(1:1)·배너(2:1)·상세 이미지(세로 길이 그대로) — 샘플 프리셋 + **실제 로컬 파일 업로드/드래그 미리보기**, 비율 경고, PC/모바일 미리보기, 가이드선, 업로드된 이미지 **우클릭 교체/삭제** 메뉴.
- 하단 바: 임시저장(시각 표시) · 취소 · 저장(필수값 검증).

### 결제 관리 `/admin/payments`
- 요약(순매출·건수·환불·입금 대기), 상태·결제수단·기간 필터, 주문번호/이름/클래스 검색.
- 테이블 + 펼침 상세(과세 구분, 공급가액·부가세, 실수령액, 승인번호, 계산서·환불 내역).
- 환불 모달(전액/부분, 금액 검증, 사유·메모), 세금계산서 발행/재발행 모달(사업자번호 자동 하이픈·10자리 검증).
- CSV 내보내기는 백엔드 연동 후.
