# 디자인 시스템

프로토타입 전 페이지에 적용된 "Toss 스타일 드라마틱 패스"(2026-09-30) 규칙을 정리했습니다.
토큰은 CSS 변수로 `src/styles/site.css`(고객용)와 `src/styles/admin.css`(관리자·결제)에 있습니다.

- 브랜드 컬러는 2026-10-14 기존 그린(`#1f9d77`, 관리자 `#00be82`)에서 **그린 계열 티파니 민트**(`#6fdcc5`)로 바꿨다. 민트로 채우는 면은 단색 대신 `--mint-grad`(민트 → 더 연한 민트)를 쓰고, 그 위 글자는 `--on-mint`.
- 메인 히어로: `#04100f → #071a19` 다크 틸 그라디언트 + 민트 radial glow.
- 메인 그라디언트 섹션: 성장 로드맵(오른쪽 위 민트 glow + 아래로 옅은 민트), 온라인 배너(`--mint-grad-soft`), 비주얼살롱 밴드(차콜 → 다크 틸 + 민트 glow).
- 성장 단계 컬러 그레이딩(클래스 목록): STEP 1 `#e8f6f5` → STEP 2 `#a9ddd9` → STEP 3 `#0aa6a1` → STEP 4 `#08706c` (짙을수록 상위 단계).
- 아카데미 소개 다크 섹션: 차콜 `#0b1716`/`#113533`, 포인트 `#9fe9e3`.

## 타이포

- 서체: Pretendard Variable (CDN) → Apple SD Gothic Neo → Malgun Gothic.
- 페이지 제목 30~32px/800, 섹션 제목 16.5~28px/700~800, 본문 14~16px, 메타 12~13.5px.
- 숫자(가격·D-day·통계)는 `font-variant-numeric: tabular-nums`, 굵게(800) 강조.
- 한글 제목은 `word-break: keep-all`로 단어 중간 줄바꿈 방지.

## 형태

- 버튼: **완전 캡슐형**(`border-radius:100px`), 기본 패딩 14px 22px, 700 weight. 주요 = 민트 채움, 보조 = 고스트(테두리) 또는 surface 채움.
- 카드: 라운드 22px(관리자 20~22px), 얇은 테두리 또는 소프트 그림자 `0 10px 24px -16px`.
- 배지: 캡슐 11~12px/700 — 모집중(민트) · 마감임박(앰버) · 마감(레드) · 개설 대기/예정·종료(회색).
- 탭바: 회색 바탕 + 선택 탭 검정 채움, 페이지 상단 sticky.
- 섹션 여백: 데스크톱 104px / 모바일 64px.

## 반응형

- 820px 이하: GNB 텍스트 메뉴 숨김.
- 900px 이하: 로드맵은 단계 이름만 표시, 선택된 단계 카드 1개만 노출, hover 이미지 숨김. 3열 그리드 → 1열.
- 960px 이하(상세): 구매박스 → 하단 고정 바.
- 640px 이하: 탭바 가로 스크롤, 좌우 여백 20px.

## 자리표시

- "예시 데이터" 점선 태그(`.ph`): 실제 콘텐츠로 교체해야 하는 영역.
- 사진 자리: 듀오톤 그라디언트 박스(소개·갤러리), 썸네일 아이콘 박스(목록), 3:8 세로 그라디언트(상세 이미지).
