# 알림톡 템플릿 (아카데미 채널)

Solapi 콘솔 → 카카오 알림톡 → 템플릿 등록에서 아래 5개를 **아카데미 카카오 채널**로 등록하고, 승인되면 템플릿 ID를 환경변수에 넣는다.
`#{...}` 변수 이름은 코드가 보내는 이름과 **글자 하나까지 같아야** 한다 (`src/lib/orders.ts`, `src/app/api/cron/notify/route.ts`, `src/app/api/admin/classes/[id]/route.ts`).
문구는 바꿔도 되지만 변수 이름은 그대로 둔다. 템플릿 ID가 없는 알림은 조용히 건너뛴다.

| 환경변수 | 언제 | 변수 |
|---|---|---|
| `KAKAO_TMPL_PAID` | 결제 완료(카드·간편결제·계좌이체), 가상계좌 입금 확인, 무료 신청 | `#{이름}` `#{클래스명}` `#{주문번호}` `#{일정}` `#{장소}` |
| `KAKAO_TMPL_VBANK` | 가상계좌 발급 직후 | `#{이름}` `#{클래스명}` `#{금액}` `#{은행}` `#{계좌번호}` `#{입금기한}` `#{주문번호}` |
| `KAKAO_TMPL_D3` | 개강 3일 전 09:00 | `#{이름}` `#{클래스명}` `#{일정}` `#{장소}` `#{준비물}` |
| `KAKAO_TMPL_EXPIRE30` | 온라인 수강 만료 30일 전 09:00 | `#{이름}` `#{클래스명}` `#{만료일}` |
| `KAKAO_TMPL_WAITLIST_OPEN` | 개설 대기 클래스를 일정 확정으로 공개했을 때 | `#{클래스명}` `#{일정}` `#{링크}` |

## 예시 문구

**KAKAO_TMPL_PAID**
```
[비주얼아카데미] 수강 신청 완료

#{이름}님, #{클래스명} 신청이 확정됐어요.

▶ 주문번호: #{주문번호}
▶ 일정: #{일정}
▶ 장소: #{장소}

개강 3일 전에 준비물과 오시는 길을 다시 안내드릴게요.
```

**KAKAO_TMPL_VBANK**
```
[비주얼아카데미] 입금 안내

#{이름}님, #{클래스명} 신청이 접수됐어요.
아래 계좌로 입금하시면 수강이 확정돼요.

▶ 입금계좌: #{은행} #{계좌번호}
▶ 입금금액: #{금액}
▶ 입금기한: #{입금기한}까지
▶ 주문번호: #{주문번호}

기한이 지나면 신청이 자동 취소돼요.
```

**KAKAO_TMPL_D3**
```
[비주얼아카데미] 개강 3일 전 안내

#{이름}님, #{클래스명} 개강이 3일 남았어요.

▶ 일정: #{일정}
▶ 장소: #{장소}
▶ 준비물: #{준비물}

오시는 길: 서울 강남구 언주로 622 (논현동, 구암빌딩) 1층
```

**KAKAO_TMPL_EXPIRE30**
```
[비주얼아카데미] 수강 기간 만료 안내

#{이름}님, #{클래스명} 수강 기간이 #{만료일}에 끝나요.
남은 강의를 마이페이지 > 온라인 수강권한에서 이어 들어보세요.
```

**KAKAO_TMPL_WAITLIST_OPEN**
```
[비주얼아카데미] 개설 알림

알림 신청하신 #{클래스명} 일정이 열렸어요.

▶ 일정: #{일정}

아래 링크에서 신청해주세요. 정원이 차면 마감돼요.
#{링크}
```

## 나머지 환경변수

| 변수 | 설명 |
|---|---|
| `SOLAPI_API_KEY` / `SOLAPI_API_SECRET` | Solapi 계정 키 (visual-auto 와 같은 계정을 써도 된다) |
| `KAKAO_SENDER_KEY` | **아카데미 채널**의 발신프로필 pfId. 비워 두면 알림톡을 보내지 않는다 (살롱 채널로 잘못 나가지 않게 기본값 없음) |
| `KAKAO_SENDER_PHONE` | 알림톡 실패 시 SMS 대체 발신번호 (선택, Solapi 에 등록된 번호) |
| `ACADEMY_CHAT_WEBHOOK_URL` | 본사 Google Chat 스페이스 webhook — 새 수강 확정·제휴 문의 알림 |
| `CRON_SECRET` | Vercel Cron 인증 (아무 긴 랜덤 문자열) |
