# 알림톡 템플릿 (아카데미 채널)

Solapi 콘솔 → 카카오 알림톡 → 템플릿 등록에서 아래 템플릿을 **아카데미 카카오 채널**로 등록하고, 승인되면 템플릿 ID를 환경변수에 넣는다.
`#{...}` 변수 이름은 코드가 보내는 이름과 **글자 하나까지 같아야** 한다 (`src/lib/orders.ts`, `src/app/api/cron/notify/route.ts`, `src/app/api/admin/classes/[id]/route.ts`).
문구는 바꿔도 되지만 변수 이름은 그대로 둔다. 템플릿 ID가 없는 알림은 조용히 건너뛴다.

| 환경변수 | 언제 | 변수 |
|---|---|---|
| `KAKAO_TMPL_PAID` | 결제 완료(카드·간편결제·계좌이체), 가상계좌 입금 확인, 무료 신청 | `#{이름}` `#{클래스명}` `#{주문번호}` `#{일정}` `#{장소}` |
| `KAKAO_TMPL_VBANK` | 가상계좌 발급 직후 | `#{이름}` `#{클래스명}` `#{금액}` `#{은행}` `#{계좌번호}` `#{입금기한}` `#{주문번호}` |
| `KAKAO_TMPL_D3` | 개강 3일 전 09:00 | `#{이름}` `#{클래스명}` `#{일정}` `#{장소}` `#{준비물}` |
| `KAKAO_TMPL_EXPIRE30` | 온라인 수강 만료 30일 전 09:00 | `#{이름}` `#{클래스명}` `#{만료일}` |
| `KAKAO_TMPL_WAITLIST_OPEN` | 개설 대기 클래스를 일정 확정으로 공개했을 때 | `#{클래스명}` `#{일정}` `#{링크}` |
| `KAKAO_TMPL_IDLE` | 온라인 강의를 3일·7일·14일 동안 안 봤을 때 09:00 (단계마다 한 번, 다시 보면 처음부터) | `#{이름}` `#{클래스명}` `#{다음강의}` `#{링크}` |
| `KAKAO_TMPL_BEHIND` | 만료 30일 안 진도 50% 미만 · 만료 7일 안 진도 80% 미만 09:00 (이게 나가는 날은 EXPIRE30·IDLE 생략) | `#{이름}` `#{클래스명}` `#{만료일}` `#{진도}` `#{링크}` |
| `KAKAO_TMPL_START` | 결제하고 1·3·7일 지나도 첫 강의를 안 틀었을 때 09:00 | `#{이름}` `#{클래스명}` `#{만료일}` `#{링크}` |
| `KAKAO_TMPL_WS_PENDING` | 영상은 다 봤는데 워크시트를 안 내고 2·7일 지났을 때 09:00 | `#{이름}` `#{클래스명}` `#{강의명}` `#{링크}` |
| `KAKAO_TMPL_HALF` | 진도 50% 를 넘는 순간 한 번 | `#{이름}` `#{클래스명}` `#{남은강의}` `#{링크}` |
| `KAKAO_TMPL_DONE` | 완강하는 순간 한 번 | `#{이름}` `#{클래스명}` `#{만료일}` `#{링크}` |
| `KAKAO_TMPL_ACCESS` | 관리자가 수강권을 주거나 기한을 바꿨을 때 (팝업에서 끌 수 있음) | `#{이름}` `#{클래스명}` `#{만료일}` `#{링크}` |
| `KAKAO_TMPL_EXPIRED` | 기한이 끝난 다음 날 09:00 (완강 못 한 사람) | `#{이름}` `#{클래스명}` `#{만료일}` `#{진도}` |

## 예시 문구

**KAKAO_TMPL_PAID**
```
[비주얼아카데미] 수강 신청 완료

#{이름}님, #{클래스명} 신청이 확정됐어요.

▶ 주문번호: #{주문번호}
▶ 일정: #{일정}
▶ 장소: #{장소}

개강 3일 전에 준비물과 오시는 길을 다시 안내드릴게요.
```

**KAKAO_TMPL_VBANK**
```
[비주얼아카데미] 입금 안내

#{이름}님, #{클래스명} 신청이 접수됐어요.
아래 계좌로 입금하시면 수강이 확정돼요.

▶ 입금계좌: #{은행} #{계좌번호}
▶ 입금금액: #{금액}
▶ 입금기한: #{입금기한}까지
▶ 주문번호: #{주문번호}

기한이 지나면 신청이 자동 취소돼요.
```

**KAKAO_TMPL_D3**
```
[비주얼아카데미] 개강 3일 전 안내

#{이름}님, #{클래스명} 개강이 3일 남았어요.

▶ 일정: #{일정}
▶ 장소: #{장소}
▶ 준비물: #{준비물}

오시는 길: 서울 강남구 언주로 622 (논현동, 구암빌딩) 1층
```

**KAKAO_TMPL_EXPIRE30**
```
[비주얼아카데미] 수강 기간 만료 안내

#{이름}님, #{클래스명} 수강 기간이 #{만료일}에 끝나요.
남은 강의를 마이페이지 > 온라인 수강권한에서 이어 들어보세요.
```

**KAKAO_TMPL_WAITLIST_OPEN**
```
[비주얼아카데미] 개설 알림

알림 신청하신 #{클래스명} 일정이 열렸어요.

▶ 일정: #{일정}

아래 링크에서 신청해주세요. 정원이 차면 마감돼요.
#{링크}
```

**KAKAO_TMPL_IDLE**
```
[비주얼아카데미] 온라인 강의 수강 안내

#{이름}님, 결제하신 #{클래스명} 강의를 최근 며칠 동안 시청하지 않으셨어요.
다음에 들으실 강의는 '#{다음강의}'예요.
하루 한 강의씩이면 수강 기간 안에 충분히 끝낼 수 있어요.

▶ 바로 이어보기
#{링크}

※ #{클래스명} 수강권을 결제하신 분께 수강 진행 상황에 따라 발송되는 안내예요.
```

**KAKAO_TMPL_BEHIND**
```
[비주얼아카데미] 수강 기간 종료 예정 안내

#{이름}님, 결제하신 #{클래스명} 수강 기간이 #{만료일}에 끝나요.
현재 진도는 #{진도}예요. 기간이 지나면 남은 강의를 볼 수 없어요.

오늘 한 강의만 이어서 들어보세요.
▶ 바로 이어보기
#{링크}

※ #{클래스명} 수강권을 결제하신 분께 수강 기간이 끝나기 전에 발송되는 안내예요.
```

> 온라인 넛지 보내는 순서·제한 (lib/nudges.ts): 한 사람에게 하루 1통, 독려(START·IDLE·WS_PENDING)는 7일에 2통까지.
> 우선순위 BEHIND > WS_PENDING > START > IDLE. `#{만료일}` 은 START·DONE·ACCESS 에선 "2027.05.31까지" / "기한 없이" 로 들어간다.
> 템플릿 원문은 Solapi 콘솔(2026-11-25 등록·검수 요청)에서 확인. D3 는 반려돼 "신청하신" 문구를 넣어 다시 올렸다.

> 검수 메모: "결제하신·신청하신"처럼 받는 사람의 행동이 문구에 없으면 반려된다 (D3 반려 사유).

## 나머지 환경변수

| 변수 | 설명 |
|---|---|
| `SOLAPI_API_KEY` / `SOLAPI_API_SECRET` | Solapi 계정 키 (visual-auto 와 같은 계정을 써도 된다) |
| `KAKAO_SENDER_KEY` | **아카데미 채널**의 발신프로필 pfId. 비워 두면 알림톡을 보내지 않는다 (살롱 채널로 잘못 나가지 않게 기본값 없음) |
| `KAKAO_SENDER_PHONE` | 알림톡 실패 시 SMS 대체 발신번호 (선택, Solapi 에 등록된 번호) |
| `ACADEMY_CHAT_WEBHOOK_URL` | 본사 Google Chat 스페이스 webhook — 새 수강 확정·제휴 문의 알림 |
| `CRON_SECRET` | Vercel Cron 인증 (아무 긴 랜덤 문자열) |
